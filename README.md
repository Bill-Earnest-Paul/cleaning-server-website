# 🧼 Cleaning Service Webpage

A responsive and visually appealing **Cleaning Service Website** built using **HTML**, **CSS**, and **jQuery**. This mini-project demonstrates the use of the **bxSlider plugin** for a smooth image slider, providing a modern and engaging user experience for a local or professional cleaning service business.

## 🚀 Features

- 🧹 **Home, Services, About Us, Contact** sections  
- 🖼️ **Image slider** implemented with `bxSlider` (jQuery plugin)  
- 📱 **Responsive design** for all screen sizes  
- 🎨 Clean and modern user interface  
- 📩 Simple contact form (front-end only)  

## 🛠️ Tech Stack

- **HTML5** – Structuring the content  
- **CSS3** – Styling and responsiveness  
- **jQuery** – DOM manipulation and plugin integration  
- **bxSlider** – Lightweight and customizable image slider  

## 📂 How to Run Locally

1. Clone this repository:  
   ```bash
   git clone https://github.com/your-username/cleaning-service-webpage.git

2. Navigate to the project folder and open index.html in your browser.
